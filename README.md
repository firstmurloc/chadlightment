# chadlightment

Prosty tracker faz sylwetki: cut → reverse → maintenance → masa.

- cel kcal i makro na dziś, wyliczany z planu faz
- dzienny wpis: waga rano, kroki, kcal, makro (zapis automatyczny)
- tygodniowe średnie i podpowiedź, czy dokładać kalorie, czy trzymać poziom
- wykres wagi ze średnią tygodniową
- dziennik treningowy z podpowiedzią ciężaru (podwójna progresja) i tabelą progresu

Wszystko działa w przeglądarce, bez serwera i bez logowania. Dane zapisują się tylko na urządzeniu, na którym otwierasz stronę (localStorage). Przycisk **Eksportuj dane** pobiera plik JSON z kopią, a **Importuj dane** wczytuje go z powrotem, np. na innym telefonie.

Na telefonie: otwórz stronę i wybierz „Dodaj do ekranu głównego”, żeby działała jak aplikacja.

Plan faz (cele kcal) jest częścią pliku z danymi. Repozytorium nie zawiera żadnych danych osobowych.
